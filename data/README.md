# Data

`synthetic/` is a fully **fictional** demo corpus generated by
`backend/tools/synthetic_data.py` (seed 42). The developers, compounds, units, prices and
policies are invented. Area names (New Cairo, North Coast, ...) are real locations, used
only for realism.

| Path | Contents | Used by |
|---|---|---|
| `synthetic/docs/*.md` | brochures, FAQ, sales policies, team-lead playbook (EN + Egyptian Arabic) | knowledge ingestion |
| `synthetic/price_sheets/*.xlsx` | per-compound price sheets: `v1` retired (June 2026), `v2` active (Oct 2026, +8%) | ingestion + stale-sheet detection |
| `synthetic/inventory/units.csv` | 240 units with status and v1/v2 prices | inventory DB seed |
| `synthetic/catalog.json` | developers, compounds, payment plans, discount limits | seeding, tests |
| `synthetic/eval/gold_qa.jsonl` | 49 gold Q&A items (EN/AR), generated from the same source so answers are always consistent | retrieval and answer evals |

Regenerate:

```bash
cd backend && uv run python tools/synthetic_data.py --out ../data/synthetic --seed 42
```
